# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analysis project that explores customer shopping trends using **Python**, **SQL (PostgreSQL)**, and **Power BI**. The project covers the full analytics pipeline — from data cleaning and feature engineering to SQL-driven business queries and interactive dashboard visualization.

---

## 📌 Project Overview

The goal of this project is to analyze a customer shopping behavior dataset (3,900 records) to uncover insights about purchasing patterns, demographics, product preferences, and promotional effectiveness. The analysis answers real business questions that can drive marketing and sales strategy.

## 📊 Dataset

The dataset contains **3,900 customer transactions** with **18 attributes**:

| Column | Description |
|---|---|
| Customer ID | Unique customer identifier |
| Age | Customer age (18–70) |
| Gender | Male / Female |
| Item Purchased | Product name (25 unique items) |
| Category | Product category — Clothing, Footwear, Outerwear, Accessories |
| Purchase Amount (USD) | Transaction amount ($20–$100) |
| Location | U.S. state (50 states) |
| Size | S, M, L, XL |
| Color | Product color (25 unique colors) |
| Season | Spring, Summer, Fall, Winter |
| Review Rating | Customer review (2.5–5.0) |
| Subscription Status | Yes / No |
| Shipping Type | Free Shipping, Express, Standard, Next Day Air, 2-Day Shipping, Store Pickup |
| Discount Applied | Yes / No |
| Promo Code Used | Yes / No |
| Previous Purchases | Count of prior purchases (1–50) |
| Payment Method | Credit Card, PayPal, Cash, Debit Card, Venmo, Bank Transfer |
| Frequency of Purchases | Weekly, Fortnightly, Monthly, Quarterly, Every 3 Months, Bi-Weekly, Annually |

## 🐍 Python — Data Cleaning & Feature Engineering

The Jupyter notebook performs the following steps:

1. **Loaded and inspected** the dataset using `pandas` (`df.head()`, `df.info()`, `df.describe()`)
2. **Handled missing values** — 37 null values in `Review Rating` were imputed with the **median rating per product category**
3. **Standardized column names** — converted to `snake_case` for consistency
4. **Created new features**:
   - `age_group` — Segmented customers into *Young Adult*, *Adult*, *Middle-aged*, and *Senior* using quartile-based binning (`pd.qcut`)
   - `purchase_frequency_days` — Mapped textual frequencies to numeric day intervals (e.g., Weekly → 7, Annually → 365)
5. **Removed redundant columns** — Dropped `promo_code_used` after confirming it was identical to `discount_applied`
6. **Exported cleaned data to PostgreSQL** using `SQLAlchemy` (with connection templates for MySQL and MS SQL Server as well)

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- PostgreSQL (or MySQL / MS SQL Server)
- Power BI Desktop (to open `.pbix` file)
- Jupyter Notebook or JupyterLab

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/KIRA832/customer-data-analysis-SQL-Python-PowerBI.git
   cd customer-data-analysis-SQL-Python-PowerBI
   ```

2. **Install Python dependencies**
   ```bash
   pip install pandas sqlalchemy psycopg2-binary
   ```

3. **Create the database** in PostgreSQL (or your preferred RDBMS):
   ```sql
   CREATE DATABASE customer_behavior;
   ```

4. **Run the notebook** — Open `Customer_Shopping_Behavior_Analysis.ipynb` and execute all cells. Update the database credentials in the connection cell before running.

5. **Run SQL queries** — Execute the queries from `customer_behavior_sql_queries.sql` in pgAdmin or any SQL client.

6. **Open the dashboard** — Launch `customer_behavior_dashboard.pbix` in Power BI Desktop.

## 📝 Key Insights

- **Clothing** is the dominant product category, accounting for the largest share of transactions
- **Male customers** generate significantly more revenue, comprising ~68% of the customer base
- **Discount usage** does not prevent above-average spending — many discount users still spend more than the mean
- **Subscription rates are low** (~27%), with subscribers and non-subscribers showing comparable spending behavior
- **Loyal customers** (>10 previous purchases) form the largest segment, indicating strong retention
